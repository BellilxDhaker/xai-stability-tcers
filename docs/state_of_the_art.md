## Foundations

Grad-CAM uses the target score gradient at a convolutional layer to produce a coarse localization map. Integrated Gradients (IG) accumulates derivatives along a path from a reference input, making that reference influential. Sliding-window Occlusion measures the change in a model score when regions are covered, so window size, stride and replacement values define what the map can resolve. [Grad-CAM](https://openaccess.thecvf.com/content_iccv_2017/html/Selvaraju_Grad-CAM_Visual_Explanations_ICCV_2017_paper.html) · [IG](https://proceedings.mlr.press/v70/sundararajan17a.html) · [Occlusion](https://arxiv.org/abs/1311.2901)

RISE introduced the deletion and insertion AUCs used here. Deletion measures how quickly the target probability falls as the most salient pixels are removed. Insertion tracks how quickly it rises as those pixels are restored. The paper explains how replacement can introduce its own evidence and uses a constant canvas for deletion and a blurred canvas for insertion. Adebayo et al. evaluate a different property by comparing maps before and after weight randomization. Their signed and absolute rank results show how visual structure can persist when attribution signs have changed. [RISE, §4.1](https://bmva-archive.org.uk/bmvc/2018/contents/papers/1064.pdf) · [Sanity Checks, §§2–3](https://arxiv.org/html/1810.03292)

## Implications for the experiment

OpenXAI motivates controlling the size of an input change when comparing neighborhoods. Binder et al. show why randomization sensitivity and faithfulness should be reported separately. DiME shows how a learned image generator can define alternatives to pixel editing. Its classifier-guided, class-changing samples answer a different question from stability under prediction-preserving changes. [OpenXAI, §4](https://papers.neurips.cc/paper_files/paper/2022/file/65398a0eba88c9b4a1c38ae405b125ef-Paper-Datasets_and_Benchmarks.pdf) · [Binder et al., §§3–4](https://openaccess.thecvf.com/content/CVPR2023/papers/Binder_Shortcomings_of_Top-Down_Randomization-Based_Sanity_Checks_for_Evaluations_of_Deep_CVPR_2023_paper.pdf) · [DiME, §§3–4](https://openaccess.thecvf.com/content/ACCV2022/papers/Jeanneret_Diffusion_Models_for_Counterfactual_Explanations_ACCV_2022_paper.pdf)

These studies leave open whether a saliency ranking changes when the same classifier is evaluated on prediction-preserving neighborhoods generated by classic transformations and by a learned decoder at comparable pixel distances. The project addresses that gap by comparing Grad-CAM, IG and Occlusion on the same Oxford-IIIT Pet sample and checkpoint. The VAE arm compares a reconstruction with a latent neighbor decoded by the same model, so both images share decoder blur. This is an approximation to the image manifold. Pixel-distance matching controls the measured change magnitude while allowing differences in texture, sharpness and semantic content. Deletion, insertion and weight randomization test complementary properties on the same study sample.
